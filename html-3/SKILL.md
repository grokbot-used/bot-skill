# 黑盒测试报告 HTML 交付规范

产出或回写**黑盒测试报告**时按本技能交付。用户明确要求 md/其他格式时再例外。不含具体需求私货；执行细则以当次用例与用户批注为准。

## 1. 交付格式
- 未特别指定格式时，**一律 HTML**。
- 文件名：`报告能力_需求名_版本号.html`（能力、需求名、版本用下划线连接）。
  - 示例：`黑盒测试报告_某需求_v1.0.0.html`
- 正文必须含**报告生成时间**，格式 `yyyy-mm-dd HH:MM:SS`（**Asia/Shanghai**）。
- 升版改结论/正文时升文件名版本号；旧版文件可保留。

## 1.1 导出表格（强制，以后每次生成）
过滤栏内必须有按钮「导出表格」（搜索之后、统计之前）。点击后下载 **CSV**（UTF-8 BOM，Excel 可直接打开）：

- 导出**当前筛选可见**条目；无可见行时提示「当前筛选无数据」，不下载空文件。
- 文件名与 HTML 同三字段，扩展名 `.csv`。
- 列与逐条字段对齐：执行用例、黑盒链路、预期结果、实际结果、测试结果、问题级别、不通过原因、耗时（秒）；**不导出截图二进制**。
- 单元格转义逗号/引号/换行；不改业务文案。打印时随 toolbar 隐藏。
- 已发版是否回改按当次用户指示；默认下一版起生效。

## 1.2 过滤栏吸顶（强制，以后每次生成）
过滤栏在页面滚动时必须固定在视口顶部，不随正文滚走。不改业务文案。

```css
.toolbar {
  position: sticky;
  top: 0;
  z-index: 20;
  background: var(--surface); /* 不透明底，禁止正文从栏下透出 */
}
```

- `--surface` 须是不透明色（如 `#FFFFFF`）；可保留边框与阴影，但不得把背景设成半透明。
- 过滤栏的祖先（`.wrap` / `main` / `body` 等）**不得**设 `overflow: hidden` 或自成一个独立滚动容器，否则 sticky 无法吸在视口顶部。
- 已发版是否回改按当次用户指示；默认下一版起生效。

## 2. 执行与证据原则
- 方法默认：**桌面控制**（按页面文案点选/输入；非自动化脚本），除非用户另行指定。
- 以已确认用例为锚点；用例不清退回用例设计澄清，不膿造步骤。
- **不把未执行写成通过**；暂停/未测与阻塞须在结论中单独计数，不得并入通过。
- 失败写清卡点；阻塞标明依赖（谁、缺什么、解除条件）。
- 正文**按用例顺序逐条**；不得只用汇总表代替逐条正文。

## 3. 问题级别（P1～P4，不用 P0）
| 级别 | 含义 |
|------|------|
| **P1** | 系统崩溃：整系统/服务不可用 |
| **P2** | 主要功能不可用：整条功能链路不可用 |
| **P3** | 次要功能不可用：分支不可用但不影响整体 |
| **P4** | 建议：需求未明确或体验/优化 |

- **未完整实现**（相对用例预期未达成）= **失败**。
- **缺材料/环境阻断**：记**失败**；原因写「缺少材料xxx」；计入失败数；级别 **P2**。若当次用例/用户明确约定「标阻塞、不硬判失败」，则记**阻塞**并在结论中单独列阻塞数，不得记为通过。
- 通过条目：问题级别与不通过原因写「无」。

## 4. 报告结构（文首）
1. 标题固定：**黑盒测试报告**
2. **需求** / 用例基线版本
3. **范围**（用例编号集、环境、账号角色；不含密钥）
4. **方法**（桌面控制等）
5. **参与人**：谁参与、各自负责内容
6. **结论**：共 x 条、通过 y、失败 z（可附阻塞/暂停数；可附 P1～P4 计数）
7. 报告生成时间（Asia/Shanghai）
8. 备注（可选）：相对上一版变更、暂停原因、依赖说明

失败/阻塞清单可在文首摘要列出（编号、级别或阻塞、一句话原因），正文仍须逐条完整。

## 5. 逐条字段（按用例顺序）
每条至少包含：
- **执行用例**（编号 + 标题/描述）
- **黑盒链路**（实际走过的入口→关键操作→核对点；写清作用，禁止空跳转）
- **预期结果**（摘自用例，可压缩）
- **实际结果**（可观察事实；含关键单号/金额/状态文案等）
- **测试结果**：通过 / 失败 / 阻塞 / 暂停（未测）
- **问题级别**：P1/P2/P3/P4，或通过/暂停时「无」
- **不通过原因**：通过时「无」；材料阻断写「缺少材料xxx」；阻塞写依赖
- **耗时（秒）**：该条执行耗时
- **截图**：仅 **1** 张——出现符合（或不符）预期结果判定依据的那一刻；不放过程连续图；内嵌或可点击放大均可（导出表格不含截图二进制）

## 6. 交付与协作
- 报告写到约定工作目录后，在约定群或私聊交付：**结论数字（x/y/z）+ 报告路径 + 用例基线 + 生成时间**。
- 不替代白盒/前后端静态推演；不改业务代码；不在群里贴密钥或超大无关附件。
- 页面/前端链路异常交前端推演；App 交 App 推演；接口/落库根因交后端推演；设备协议交模拟设备角色；用例歧义交用例设计。
