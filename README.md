# bot-skill

Grok Bot 中各 bot 的用户技能备份。每个子目录对应一项技能，核心文件是 `SKILL.md`。目录名是技能 id，标题以文件开头的 `name` 字段为准。

当前收录：

- `app`：APP静态推演报告
- `app-2`：APP静态推演流程
- `web`：Web前端静态推演流程
- `skill-1793763441671`：前端静态推演报告
- `html-2`：html-2（后端静态推演 HTML 报告）
- `skill-1793763456915`：后端静态推演流程
- `html`：html（测试用例 HTML 交付规范）
- `html-3`：html-3（黑盒测试报告）
- `skill-1793763441647`：协议设备模拟
- `enable-openapi-payg-on-justrack`：Enable OpenAPI PAYG on JusTrack

本仓库只存放这些技能原文，不包含平台内置技能。
